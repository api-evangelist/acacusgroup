# Acacus Group

> Acacus Group (Acacus Technologies) is a Dubai-headquartered mobility technology company founded in
> 2013 that builds artificial-intelligence and machine-learning software for the transportation and
> airline industries. Its Lynx product family provides intelligent fleet management, optimized
> dispatch, disruption management, telematics and deep-learning in-vehicle video analytics; it also
> develops autonomous vehicle technology and Peregrine for airline crew and airport operations.

Acacus does not publish a public API. As of 2026-09-06 there is no developer portal, no API
reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK on any public package registry, no MCP
server and no agent card. Lynx is sold as an enterprise SaaS subscription through a demo request.
This file is generated by API Evangelist from the public company surface; it is not published by
Acacus Group.

## Products

- [Lynx — Intelligent Fleet Management](https://www.acacusgroup.com/intelligent-fleet-management-lynx): Fleet management, optimized dispatch, telematics and vehicle diagnostics. Lynx Pro adds disruption management, planning/constraint configuration and driver scorecards; Lynx Vision adds in-vehicle video recording and deep-learning analytics for driver fatigue, lane departure, tailgating and passenger counting.
- [Autonomous Vehicle Technology](https://www.acacusgroup.com/autonomous-vehicle-technology-acacus): Autonomous vehicle prototype and platform work, road-tested from 2017.
